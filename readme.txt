== Description ==

افزونه جلوگیری از دانلود ویدیو برای وردپرس و المنتور — از دانلود ویدیوهای سایت شما جلوگیری می‌کند.

قابلیت‌ها:

* غیرفعال کردن راست‌کلیک روی ویدیوها
* غیرفعال کردن میانبرهای کیبورد (Ctrl+S, Ctrl+U, F12, Ctrl+Shift+I/J/C)
* غیرفعال کردن کشیدن (Drag & Drop) ویدیو
* غیرفعال کردن دکمه دانلود در کنترل‌های ویدیو (Chrome, Safari, Edge)
* پنهان کردن دکمه Picture-in-Picture
* غیرفعال کردن کنسول توسعه‌دهنده
* تار کردن صفحه هنگام باز شدن DevTools
* افزودن واترمارک متنی روی ویدیوها
* حفاظت از ویجت‌های ویدیو المنتور
* پشتیبانی از ویدیوهای بارگذاری‌شده داینامیک (AJAX, lazy-load, پاپ‌آپ المنتور)
* عدم تداخل با افزونه‌های دیگر

== Installation ==

1. پوشه `prevent-video-download` را در مسیر `wp-content/plugins/` آپلود کنید.
2. افزونه را از صفحه افزونه‌های وردپرس فعال کنید.
3. از منوی «جلوگیری از دانلود ویدیو» در پیشخوان وردپرس تنظیمات را پیکربندی کنید.

== Frequently Asked Questions ==

= آیا این افزونه با المنتور کار می‌کند؟ =

بله، این افزونه به‌طور کامل از ویجت‌های ویدیو المنتور پشتیبانی می‌کند.

= آیا با افزونه‌های دیگر تداخل دارد؟ =

خیر، این افزونه به‌گونه‌ای طراحی شده که با افزونه‌های دیگر تداخل نداشته باشد.

= آیا از دانلود کامل جلوگیری می‌کند؟ =

هیچ روشی نمی‌تواند دانلود را ۱۰۰٪ متوقف کند، اما این افزونه راه‌های رایج دانلود را مسدود می‌کند و کاربران عادی قادر به دانلود نخواهند بود.
